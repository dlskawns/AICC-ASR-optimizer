# aicc_task_designer

TASK: Design the downstream AICC TA task and semantic-critical error taxonomy.

## Task Candidates

- Cancellation/termination inquiry.
- Payment/billing issue.
- Delivery/order status.
- Date/time change.
- Product plan change.
- Complaint escalation.

## Semantic-Critical Classes

- Negation flip.
- Amount mismatch.
- Date/time mismatch.
- Product/entity mismatch.
- Intent flip.
- Missing request.
- Clarification needed but not triggered.

## Output

```text
Verdict:
Evidence:
Claims:
Open Risks:
Next Leads:
```

For each task, include example utterances, slot schema, failure cases, and evaluation metric.
