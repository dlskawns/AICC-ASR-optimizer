# experiment_designer

TASK: Design experiments that could survive top-tier review.

## Required Outputs

- Baseline table.
- Dataset split policy.
- Condition matrix.
- Metrics.
- Ablations.
- Statistical test or confidence interval plan.
- Failure analysis taxonomy.

## Mandatory Metrics

Include WER/CER and at least one downstream or semantic-critical metric:

- Intent Accuracy.
- Slot F1.
- Negation Error Rate.
- Number/Date Error Rate.
- Entity Error Rate.
- Task Success Rate.
- Clarification Precision/Recall.
