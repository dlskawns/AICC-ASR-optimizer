# Related Work Archive

`related-work.yaml`은 citation 후보를 관리한다.

Status values:

- `candidate`: 첨부 논의나 기억에서 나온 항목. 아직 원문 미확인.
- `verified`: 원문 또는 공식 페이지 확인 완료.
- `needs_reading`: 존재는 확인했지만 세부 claim을 원문에서 더 읽어야 함.
- `refuted`: 제목, 연도, 결과, 관련성이 틀렸거나 과장됨.

각 항목은 가능한 경우 URL, DOI/arXiv/ACL Anthology, venue, relation, novelty threat를 포함한다.
