# Evaluation Surface

## ASR Metrics

- WER.
- CER.
- Dialectal token error rate.
- Complex coda / phonological phenomenon error rate.
- Confidence calibration on critical spans.

## Semantic-Critical Metrics

- Negation Error Rate.
- Number Error Rate.
- Date/Time Error Rate.
- Entity Error Rate.
- Intent-Flip Error Rate.

## Downstream Metrics

- Intent Accuracy.
- Slot F1.
- TA category accuracy.
- Task Success Rate.
- Clarification Precision/Recall.

## Reporting Rule

Every ASR result table must include at least one downstream or semantic-critical metric. WER/CER-only tables are allowed only for preliminary diagnostics.
